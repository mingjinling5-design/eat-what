# Eat What 校园食堂智能点餐推荐系统

## 项目简介

Eat What 是一个面向大学生的校园食堂智能点餐推荐系统，主要用于解决学生在食堂点餐时“不知道吃什么”“选择困难”“想吃得更健康”等问题。

本项目围绕校园食堂真实使用场景进行设计，通过菜单管理、菜品展示、图片上传、用户偏好选择和点餐推荐等功能，为用户提供更加方便、快捷的点餐体验。系统采用前后端分离开发方式，前端负责页面展示和用户交互，后端负责接口服务和数据处理，具有较好的扩展性和实用价值。

## 项目背景

在大学生活中，食堂是学生日常就餐的重要场所。但很多学生每天都会遇到“今天吃什么”的问题。面对食堂中种类较多的菜品，用户往往需要花费较多时间进行选择。

因此，本项目设计了一个校园食堂智能点餐推荐系统，希望通过数字化方式帮助学生快速选择合适的菜品。系统可以根据用户偏好、菜品信息和推荐规则，为用户生成点餐建议，从而提升点餐效率和校园生活体验。

---

## 主要功能

### 1. 菜单图片上传

系统支持上传菜单图片，方便用户保存和查看食堂菜单信息。

### 2. 菜品信息展示

系统可以展示菜品名称、价格、分类等基础信息，方便用户快速浏览食堂菜品。

### 3. 智能点餐推荐

系统可以根据用户的口味偏好、菜品类型、价格等条件，为用户推荐适合的菜品，帮助用户快速做出选择。

### 4. 健康饮食推荐

系统可以向健康饮食方向扩展，例如根据热量、营养搭配、饮食习惯等因素进行推荐。

### 5. 前后端分离

项目采用前后端分离结构，前端负责页面展示，后端负责数据接口和业务逻辑，便于后续维护和功能扩展。

## 运行方法

### 一、克隆项目

```bash
git clone https://github.com/mingjinling5-design/eat-what.git
cd eat-what
```

---

### 二、启动后端

进入后端目录：

```bash
cd backend
```

创建虚拟环境：

```bash
python -m venv .venv
```

激活虚拟环境：

```bash
.venv\Scripts\activate
```

安装后端依赖：

```bash
pip install fastapi uvicorn python-multipart
```

启动后端服务：

```bash
python -m uvicorn main:app --reload
```

后端默认运行地址：

```text
http://127.0.0.1:8000
```

---

### 三、启动前端

重新打开一个终端，进入前端目录：

```bash
cd frontend
```

安装前端依赖：

```bash
npm install
```

启动前端项目：

```bash
npm run dev
```

前端默认运行地址：

```text
http://localhost:5173
```

## 项目特色

### 1. 贴近校园生活

项目选题来源于大学生日常食堂点餐场景，具有较强的现实意义和实用价值。

### 2. 操作简单

用户可以通过简洁的页面完成菜单查看、图片上传和菜品推荐，使用门槛较低。

项目采用前后端分离开发方式，结构清晰，便于维护和二次开发。

### 5. 推荐逻辑清晰

系统初期可以采用规则推荐方式，后续可以进一步升级为基于机器学习的个性化推荐系统。
